# 第 25 课：智能体发展史 —— 从符号主义到 LLM 驱动

> 核心问题：AI Agent 不是 2023 年才出现的概念，它的前身可以追溯到 1950 年代。理解历史，才能看清方向。
> 预计时间：1-2 天

---

## 一、从你最熟悉的说起

作为 Java 开发者，你写过的最"智能"的程序可能是基于规则的系统：if-else 匹配条件。这就是"告诉程序怎么做"。

现在想象一个系统，它**自己决定**该做什么、怎么做、做完了没有。这就是"智能体"的核心思想，已经发展了 70 多年。

---

## 二、四个时代

### 2.1 符号主义（1950s-1970s）

核心思想：智能 = 符号操作，把问题变成逻辑推理。

类比：像走迷宫时记住"死胡同就回头"，用纸条记录"这个路口试过了"。

| 成果 | 年份 | 做了什么 |
|------|------|---------|
| Logic Theorist | 1956 | 证明数学定理 |
| General Problem Solver | 1959 | 通用问题求解器 |
| SHRDLU | 1970 | 在积木世界中理解自然语言 |
| 专家系统 MYCIN | 1976 | 诊断血液感染疾病 |

局限：SHRDLU 只能处理积木世界，换一个场景就完全失效。

Java 中的对应：规则引擎（Drools）、状态机（Spring StateMachine）都是符号主义的遗产。

### 2.2 联结主义（1980s-2000s）

核心思想：智能 = 神经网络中涌现的模式识别。

类比：符号主义像"按说明书操作"，联结主义像"看一万张猫的照片，自己学会什么是猫"。

| 年份 | 事件 | 意义 |
|------|------|------|
| 1986 | 反向传播算法 | 训练多层神经网络 |
| 1997 | IBM 深蓝 | 搜索 + 评估函数 |
| 2006 | 深度学习 | 多层网络训练方法 |
| 2012 | AlexNet | 深度学习爆发 |

强化学习是 Agent 概念的萌芽：Agent 观察环境 -> 采取行动 -> 获得奖励/惩罚 -> 调整策略 -> 重复。

### 2.3 统计学习（2000s-2017）

关键转变：从"人写规则"到"人写模型 + 数据训练"。

```java
// 符号主义：人写规则
if (text.contains("面试")) { return "推荐"; }
// 统计学习：模型自己学到
double score = model.predict(text);
```

### 2.4 LLM 驱动的智能体（2023-至今）

LLM 的突破：它是一个通用认知引擎。

```
传统程序：输入 -> 固定逻辑 -> 输出
LLM Agent：目标 -> 自主规划 -> 选择工具 -> 执行 -> 观察 -> 调整
```

| 年份 | 事件 |
|------|------|
| 2022.11 | ChatGPT 发布 |
| 2023 | AutoGPT / LangChain |
| 2024 | MCP 协议发布 |
| 2025 | DeepSeek-R1 / A2A 协议 |

## 三、发展脉络

```
符号主义（规则驱动）-> 联结主义（数据驱动）-> 统计学习（特征工程）
-> Transformer（自监督学习）-> LLM Agent（目标驱动）
```
